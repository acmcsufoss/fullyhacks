# FullyHacks – Web Frontend

This is the React + Vite + Tailwind CSS frontend for the FullyHacks hackathon site.

The app is designed to be deployed via Firebase Hosting from the project root.

## Tech Stack

- React + React Router + TypeScript
- Vite
- Tailwind CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Format and lint:

```bash
npm run format
npm run lint:fix
```

Start:

```bash
npm run dev
```
